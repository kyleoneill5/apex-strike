# Third-party assets cleared for this build

## `models/ppl_soldier.glb`

Original character built for DOMINION (helmet, vest, limbs, walk cycle). It is not a Mixamo file.
Released with this repository under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Bone names (`mixamorig:Head`, `Spine2`, `RightArm`, `LeftUpLeg`, and the rest of that set) and clip names `Idle`, `Walk`, `Run` match the hooks in `dev/src/ppl_people.js`.

The previous file was the three.js example soldier (Mixamo). That file is removed. Do not put it back.

## `tex/us_sat_bmng.jpg`

NASA Blue Marble imagery, public domain (U.S. Government work).
This crop (about 127.5°W–57.5°W, 15°N–60.7°N) was cut from the equirectangular Earth map shipped with three.js r160
`examples/textures/planets/earth_atmos_2048.jpg`, which three.js attributes to NASA.
Source page: https://visibleearth.nasa.gov/
Upstream file used for the crop: https://github.com/mrdoob/three.js/blob/r160/examples/textures/planets/earth_atmos_2048.jpg
